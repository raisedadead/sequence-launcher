# AGENTS.md

Sequence Launcher is a Raycast extension for macOS. One hotkey opens the command; the typed key sequence opens an application, a folder, or a URL without Return.

- User behavior, keys, and setup: `README.md`. Keep its Keys table in sync with every action or shortcut change.
- Manual checks for keyboard input, focus, and the editor: `docs/TESTING.md`.

## Module boundary

Pure modules import nothing from `@raycast/api`, so the tests load them without Raycast:

- `src/config.ts`: schema, validation, location-specific errors.
- `src/sequence.ts`: exact matching of a key sequence, the place for a new binding, and the flat list of destinations.
- `src/edit.ts`: add, update, and remove a binding by its key sequence; suggest a free key; choose what Bind This captures.
- `src/execution.ts`: launch coordinator and destination resolution.

Raycast and file-system adapters: `src/destinations.ts`, `src/bindings-file.ts`, `src/trace.ts`, `src/presentation.ts` (row icons and text), `src/surface.tsx` (List or Grid), `src/sequence-launcher.tsx` (launcher), `src/search-bindings.tsx`, `src/bind-this.tsx`, `src/binding-form.tsx` (editor).

## Invariants

- The search text is the sequence buffer. Group entry keeps the text. Launch happens in `onSearchTextChange`, without debounce, throttle, or a timer.
- Matching is exact. ASCII `A`–`Z` fold to lowercase; any other character makes the sequence invalid. Input beyond a leaf is invalid, never truncated.
- One valid sequence gives one launch attempt. The coordinator latch is set before the first `await`, stays set across a reload, and a generation counter drops results that arrive after a reload or unmount.
- A callback value equal to the previous value is ignored. After a failure, only Retry or a changed sequence launches again.
- An invalid bindings file disables launching and shows location errors.
- An editor save compares the file text with the load snapshot and refuses on a difference. It writes a temporary file, keeps the file mode, renames it over the real path, and follows a symbolic link to its target.
- The extension runs no shell command, sends no network request (so no `getFavicon`), and has no telemetry. The trace is development-only and records sequences and timing, never destination paths or URLs.
- Empty groups are valid, because the editor makes a group before its first binding.
- A URL can use any scheme except `file:` (a folder binding does that) and `javascript:`. It must not contain a user name or password.
- Bind This saves at most once per run. It reads the Finder selection, the clipboard, and the front app only at start, and it skips Raycast as the front app.
- The product is distinct from other key launchers. Code, docs, UI text, and commit messages do not name, quote, or copy one.

## Runtime facts

- Development mode runs each effect two times: mount, unmount, mount.
- `closeMainWindow` unloads the command before the next `await` resolves, so code after a successful launch does not run. A fresh invocation starts clean because the close uses `PopToRootType.Immediate`. UNVERIFIED: `showHUD` with the same options, used by Bind This after a save, behaves the same.
- The launch order is: open the target, then close the window with `closeMainWindow`. A successful launch shows no message; a failure shows a toast.

## Verification

- `npm test` proves logic only. A change to input handling, the view, or the launch path also needs the manual checks in `docs/TESTING.md`; report a check as passed only after a person runs it in Raycast.
- The development trace is `trace.jsonl` in `environment.supportPath`. Count `execute-request` events for each `invocation` to find duplicate attempts.
- `raycast-env.d.ts` is generated by `ray build` and `ray develop`, and it is gitignored. The typecheck does not need it.

## Keys

Action shortcuts use only `Keyboard.Shortcut.Common` (⌘N, ⌘E, ⌃X, ⌘R, ⌘O). Raycast gives Return to the first action and ⌘Return to the second action of each row; keep **Reset Sequence** as the second row action.

## Scope

Public Raycast APIs only: no native helper, no global key interception, and no change to hotkeys or system settings. The manifest has no `publish` script.
